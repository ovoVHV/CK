# 库如何告诉 CK AI 自己会什么

版本：9.1.0-alpha.35。继续使用现有 `ck-blocks.json`，无需添加 MCP 程序、AI 专用脚本或作者自己生成的质量报告。

CK 当前 AI 使用内部工具调用；本次接通库能力数据，并未开放独立的标准 MCP 服务端。以后若提供 MCP 适配层，应复用同一套查询与校验逻辑，避免出现两套库定义。

## 作者写什么

| 已有字段 | 应填写的内容 | AI 用途 |
|---|---|---|
| 包级 `keywords` | 设备名称与功能关键词；具体能力写在积木语义中 | 查找当前板卡已加载的库与积木 |
| 积木 `semantics.purpose` | 做什么，如读取温度、控制电机方向 | 按能力检索，不依赖积木类型名 |
| `semantics.behavior` | 真实执行顺序、是否要初始化、是否阻塞、失败时怎样返回 | 理解正确使用方法 |
| `semantics.side_effects`、`concepts` | 对串口、总线、输出、计时的影响和相关概念 | 避免把有副作用的调用当纯计算 |
| `fields`、`inputs` | 参数名称、含义和默认值 | 结合运行时真实字段与连接构造积木 |
| `output` | 返回类型、单位、错误值或可空性说明 | 区分厘米/微秒、正常读数/错误值 |
| `dependencies` | 库、头文件、Core 或能力依赖 | 解释前置要求；不会自动安装 |
| `hardware.resources`、`hardware.claims` | 资源来自哪个字段/输入、用途、共享/冲突规则 | 读取硬件用途；资源检查仍由既有检查器执行 |
| `constraints` | 采样间隔、调用顺序、范围、板卡限制及恢复办法 | 提交方案前读取使用限制 |
| `generation` | 生成的调用、include、全局初始化及说明 | 理解对应代码的语义，不以示例代码替代积木 |
| `examples` | 示例参数、使用步骤和预期行为 | 参考用法；不自动读取文件或执行示例 |
| `errors` | 错误原因、错误值和恢复办法 | 解释问题与修复建议 |

作者不必知道用户把设备接在 5 还是 6。作者声明“触发信号来自 TRIG 输入，作为数字输出”，用户在工程里选具体引脚，CK 读取当前值。不能把作者声明当作用户已经正确接线或做过真机验证。

## 片段示例

下面是一个虚拟测距接口的文档片段，演示如何描述能力，不是完整可安装库，也不代表某种真实传感器的参数。实际作者应填写自己实现的真实行为。

```json
{
  "semantics": {
    "purpose": "测量物体距离",
    "behavior": "初始化后触发测量；等待回波最多30毫秒，超时返回-1。",
    "side_effects": ["测量期间阻塞当前调用"],
    "concepts": ["测距", "距离", "超声波"]
  },
  "output": {
    "connection": "value",
    "types": ["Number"],
    "unit": "cm",
    "description": "距离厘米值；-1表示测量失败"
  },
  "constraints": [{
    "id": "sample-interval",
    "severity": "warning",
    "description": "两次调用至少间隔60毫秒",
    "message": "采样间隔过短可能得到无效结果",
    "recovery": "用非阻塞定时控制调用频率，并处理-1错误值"
  }]
}
```

作者选择现有 v2 格式时，继续按 v2 规范补齐必填节；这不是新增的 AI 门槛。旧版库不强制升级，也仍能通过运行时积木结构、已有说明与示例使用 AI。未声明的行为保留为未知，CK 不猜测不存在限制。

## CK 怎样读取

1. `list_libraries`：当前板卡已加载且可用的库、能力摘要和积木数量。
2. `search_blocks`：按功能、概念、副作用、硬件用途检索；可限定 `libraryId`。
3. `get_block_schema` / `get_block_schemas`：读取真实注册的字段、下拉、连接和能力摘要。文档不能代替这一步的结构校验。
4. `get_block_documentation`：按节分页读取完整声明，例如 `semantics`、`output`、`hardware`、`constraints`、`examples`、`errors`。
5. AI 根据当前工程提出可编辑积木方案，用户预览确认后应用，仍可撤销并执行本地编译。

目录列表不等于所有已安装库或在线商城；未加载、不适配当前板卡或未注册的积木不对 AI 冒充可用。工具返回 `declared`（作者声明）、`adapted`（兼容适配）、`undeclared`（未声明），以及分页指针。大记录不会被静默截断成“没有限制”。

库文档只是资料，其中夹带的指令不能覆盖系统规则或授予新工具权限。示例路径不会被自动打开，依赖不会被自动安装，声明不会被包装成真实硬件通过。AI 仍可能误解说明或犯逻辑错误，编译与行为复核需要分别进行。
