CK 9.1.0-alpha.38 · AI 制作积木库

AI 侧栏新增“制作积木库”模式。填写功能、硬件型号、操作与参数，AI 分段生成声明式积木、代码规则和必要的 Arduino C/C++ 文件。软件生成标准 library.json、ck-blocks.json v2、工具箱和示例，质量报告由 CK 检查后生成。

默认勾选“验证通过后自动安装并加载”。取消勾选后，可先查看文件清单与试编译代码，再点击“安装并加载”。已加载库进入积木分类、搜索和 AI 可用库目录，无需手动复制或压缩。

支持导出标准 ZIP 供库管理器导入。生成库包含版本号；已有包标识不会被自动覆盖；显示名称相同但包标识不同的库可以同时加载，升级已有库继续使用库管理器的迁移机制。

结构、字段连接、生成器占位符和 CK v2 规范均经过检查；试编译覆盖每个积木的默认或声明样本。失败最多再修复两次，未通过不安装。编译结果绑定当前 FQBN、Core、源码和库内容摘要。内容改变、会话授权丢失后不能沿用旧验证。安装后加载失败会回滚，未完成的安装在下次启动恢复。

范围：声明式 JSON 积木和生成规则；源文件为 src/ 下的 h/hpp/c/cpp。暂不生成桌面 JS、mutator、自定义执行脚本，不自动下载依赖，不自动上传。新库默认只声明当前验证板卡兼容，不把一次编译推广为全部板卡通过。

编译通过不保证硬件通信、程序逻辑或所有参数组合正确；未知硬件仍需提供可靠协议与 API 资料，并进行真机验证。导出前请审阅源码来源和许可，CK 不伪造第三方再分发授权。

同时修复自动恢复稿漏传板卡配置的问题：前端摘要包含的构建目标现在完整传递给宿主，避免配置就绪后自动保存被摘要校验拒绝。
