# alpha.49 源码界面修复与发布验证

验证日期：2026-11-17。此版本调整源码界面与模式切换，不改变编译算法、输入内容证明或回退策略。

## 界面变化

- 移除占用单独一排的模式说明栏；“积木 / 源码”合并到现有顶部工具栏。
- 文件栏仅保留文件名、未保存状态与“源码操作”菜单；导入、导出、从积木重新生成集中放入菜单。
- 源码模式完整隐藏 Blockly 区域，修复分类图标覆盖代码；切回积木时重新测量工作区。
- 模式切换保留同一源码编辑器实例及光标、滚动、撤销记录；不同工程仍使用独立状态。
- 调整代码行距、活动行、深浅主题与窄窗口布局，并支持模式标签键盘导航。

## 最终安装包验证

从最终 NSIS 安装包解压的 EXE、Node、Ninja、控制器及 Rust 助手运行测试，普通用户权限，未注入替代前端资源。文件选择器回答由测试提供，实际保存、编译、取消和 IPC 未模拟。此轮没有执行安装向导或实体板上传测试。

- 594 个载荷文件逐项核验长度和 SHA-256；安装包不含内部审计目录。
- 连续 20 轮积木 / 源码往返切换；414 个采样帧未发现源码区显示 Blockly 表面或搜索浮层。
- 同一编辑器、手写源码、撤销重做、长文件滚动与光标保留。
- 检查 1280×800、1024×768、900×650 浅色，以及 900×650、1440×900 深色布局；工具栏无交叠，相关控件位于视口内。
- “源码操作”菜单通过 Esc、外部指针关闭；错误行提示、覆盖取消、未保存离开提示、实际工程保存重开、检查点、恢复稿及 .ino 导入导出通过。
- 实际 Uno 与 ESP32-S3 首次、改码、相同源码构建通过；切回积木时编译输入确为积木生成代码。源码错误和用户取消均按预期返回失败状态。
- 公开源码目录的相关编辑器、版本 / 安装契约测试合计 12 项及 47 个引擎模块语法检查通过；网站签名清单相关 5 项测试通过。
