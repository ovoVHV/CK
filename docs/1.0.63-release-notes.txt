CK LAB V1.0.63

1. 修复「积木与库 → 在线获取 → CK 积木库」切换 Gitee / GitHub 平台源不生效的问题：
- 切换平台下拉框（Gitee / GitHub / 自动）时自动切换并记忆各平台对应的仓库地址（Gitee 默认 `https://gitee.com/manong1234/makerlib.git`，GitHub 默认 `https://github.com/ovoVHV/CK-Libraries.git`），不再把 GitHub 地址残留到 Gitee 下导致报错或继续显示旧列表；
- 自动纠偏旧版 `localStorage` 中残留的「Gitee + GitHub 地址」错配缓存；
- 切换平台或重新读取时立即清空旧列表、重置分类与勾选状态，并增加请求序号防止慢请求回写覆盖新结果；
- 手动输入另一平台仓库地址并点击「读取仓库」（或回车）时自动同步下拉框平台选项；
- 为在线品牌 Logo 与模块缩略图补充 `no-referrer`，修复 Gitee 在线仓库图片因 Referer 防盗链显示空白的问题。

2. 同时保留 V1.0.62 的多文件增量编译加速、V1.0.61 的积木库品牌分类/实物缩略图及积木拖出渲染同步修复。
V1.0.60–V1.0.62 用户可在 CK 主页直接在线更新，或下载 V1.0.63 安装包覆盖安装到原目录，无需卸载或重装核心包。
