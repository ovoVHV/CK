# alpha.48 发布与验证范围

版本：9.1.0-alpha.48，Windows x64 预览版。发布日期：2026-11-17。

本版在现有工程编辑区加入“积木 / 源码”切换，手写 Arduino C/C++ 与积木共用工程、完整板卡配置、编译、上传、串口和日志。没有另建独立源码工作台。使用方法及限制见 [源码编程说明](source-editor.md)。

## 本版已完成的验证

- 47 项相关前端测试通过，覆盖实际 CodeMirror 编辑器、源码状态、板卡目标、恢复稿、未知积木保护与延迟加载；另有 3 项版本和安装存储契约测试通过。
- TypeScript/Vite 生产构建、桌面 Rust release 构建和安装包构建通过。
- 从最终安装包提取的 592 个载荷文件逐项核验大小与 SHA-256。
- 使用最终安装包中的桌面 EXE、Node、Ninja 和控制器，以普通用户身份完成真实桌面 IPC 测试。覆盖源码切换与保留、保存和重新打开、恢复、.ino 导入导出、错误行、取消和浅色/深色布局。
- 使用 Arduino AVR Core 1.8.8 的 Uno 与 ESP32 Core 3.3.6 的 ESP32-S3 WiFi 程序进行真实编译，验证编辑后的实际源码传入编译入口。

| 本机功能样本（点击编译至界面完成） | 首次 | 改码 | 相同源码 |
| --- | ---: | ---: | ---: |
| Uno，Core 1.8.8 | 6.607 秒 | 2.563 秒 | 1.713 秒 |
| ESP32-S3 WiFi，Core 3.3.6 | 59.896 秒 | 20.753 秒 | 7.041 秒 |

每格仅一次功能样本，不是 P95、双机资格或与官方路径的 A/B 对照。ESP32-S3 改码样本实际执行 1 次对象编译、1 次链接、2 次镜像任务，沿用 70 个对象；相同源码样本原生构建任务为零。不能据此承诺所有工程、电脑和 Core 的速度。

本版没有进行实体硬件上传或运行验证，也不声明整个仓库的所有测试已通过。源码模式目前为单文件 Sketch（UTF-8 上限 1 MiB），不提供多文件工程或源码 AI/调试。
