CK LAB V1.0.64

1. 支持多开窗口与同时打开多个 CK 工程：
- 解除启动器（`CK-V9.1.exe`）与桌面端（Tauri `single_instance`）对普通会话的单实例拦截：在已打开 CK LAB 的情况下，可直接从桌面、开始菜单或资源管理器双击其他 `.ck` / `.maker` 工程文件新开独立窗口，不再弹出「CK V9.1 已在运行或测试中，请先关闭当前会话」；
- 保留共享存活会话句柄（`Local\CK-V91-Product-Launcher`）与独占维护锁（`Local\CK-V91-Exclusive-Session`），多窗口运行时安装器、卸载器与自动更新仍可准确检测并保护文件安全；同时隔离并发启动日志（`launcher-<pid>.log`）与 `arduino-cli.yaml` 原子写入；
- 启动器弹窗标题统一为 `CK LAB`，并按 Windows 系统语言自动显示中文或英文提示。

2. 安装包全面支持英文与简体中文双语：
- Windows NSIS 安装程序新增语言选择对话框（English / 简体中文，自动匹配系统语言并记住选择；自动更新静默安装 `/S` 自动跳过交互弹窗）；
- 全部自定义界面（含数据保存位置页）、运行中拦截提示、卸载校验提示与开始菜单快捷方式均提供完整中英文双语 `LangString`，并附带英文 `README.txt` 与中文 `使用说明.txt`；
- 升级时自动清理旧版 `CK V9.1 测试版` 快捷方式并统一为 `CK LAB`。

3. 修复主页工程卡片将第三方开发板（如 Emakefun BLE-Uno / RF-Nano）错显示为官方 Arduino UNO 图片与 `UNO` 标签的问题：
- 主页「最近打开的工程」、卡片网格视图与列表视图均优先读取对应板卡包自带的实物板图（`boardPkg.icon`）与板卡型号标签（如 `BLE-UNO` / `RF-NANO`），不再仅按底层 `fqbn`（`arduino:avr:uno`）回退成官方 UNO 封面图。

4. 补齐桌面端全英文（English）界面与深度编译流程本地化：
- 新增响应式双语辅助模块 `i18n/uiText.ts`，消除切换到 English 后仍残留中文的核心组件与深度流程：包含工作区顶栏/菜单/未保存弹窗/串口监视器/状态底栏、积木↔源码切换与源码编辑面板、工程文件树、AI 积木助手、编译目标设置、未知积木保护页、板卡护照、设备体检与数据存储设置；
- 补全 170+ 条 Blockly 内置积木与工具箱英文翻译（修复中英混排与未翻译分类项），并完整本地化编译初始化/构建进度/构建日志、编译错误诊断卡片与积木气泡、工程体检（编译诊断/资源占用/引脚冲突风险提示）、项目检查点、最近可用版本对比及工程验收报告（含打印导出）；
- 修复工作区阻塞提示页（工程已停止载入 / 未知积木只读保护 / 积木外观恢复停止）层级低于左侧 Blockly 工具箱（`z-index: 70`）导致左侧内容与按钮被遮挡的 UI Bug。

V1.0.60–V1.0.63 用户可在 CK 主页直接在线更新，或下载 V1.0.64 安装包覆盖安装到原目录，无需卸载或重装核心包。
