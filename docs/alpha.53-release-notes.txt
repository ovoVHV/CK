CK V9.1.0-alpha.53 · 多文件工程、AI 与串口调试

积木和源码模式均可浏览工程文件树，管理同一工程中的 C/C++ 文件。AI 可查看工程目录，并按当前授权在工程内创建文件。
AI 支持选择 Chat Completions 或 Responses 接口。设备权限集中在二级面板；串口读写和修复后上传一次需要明确开启。
本版同时提供按钮消抖、非阻塞定时器、滑动平均三个独立 CK 库及批量制库工具箱。每库自带 C++ 驱动和正常、报错示例。
三库在 Uno Core 1.8.8 测过桌面编译、标红、定位和修正后重编；ESP32-S3 Core 3.3.6 测过生成固件。未做三库的实物接线验收，本次不发布新的性能成绩。
