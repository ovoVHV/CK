CK LAB V1.0.61

1. 库管理器新增积木库厂商分类与品牌图片展示（覆盖「已安装」与「在线获取 → CK 积木库」）：
- 分类栏支持「全部」「通用库」以及各公司品牌分类（如 Emakefun 等），未声明 vendor 的积木库（仅 author）继续归入「通用库」并保持简洁列表样式；
- 积木包沿用 CK 标准 schema v2 格式与完整证据护照/质量门禁，仅需在 library.json 中可选追加 vendor、vendor_logo、icon（本地相对 PNG/SVG/WebP/JPEG，最大 256 KiB），即可在本地离线与 Gitee/GitHub 在线仓库中安全展示厂商 Logo 与模块缩略图；
- 卸载某厂商最后一个库后自动切回「全部」，不会停留在空白页。

2. 修复所有积木从工具箱拖出时的颜色渲染不同步问题：
- 修正扩展积木颜色注册覆盖、工作区变更监听闭包陈旧以及拖拽层 DOM 皮肤同步问题，确保内置与第三方扩展积木在拖拽中和落位后颜色始终一致，无需再点击其他积木刷新。

同时保留 V1.0.60 的目标板厂商 Logo 分类栏、冷热编译策略、Windows 深目录修复与离线外设样板库。
V1.0.60 用户可在 CK 主页直接在线更新，或下载 V1.0.61 安装包覆盖安装到原目录，无需卸载或重装核心包。
