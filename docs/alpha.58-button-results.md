# alpha.58 安装包按钮验收

Windows 普通用户；同机，使用两份正式构建的桌面、控制器、运行时及工具。每个版本和板卡启动独立进程、使用新构建目录。按实际工具栏按钮，计到进度浮层关闭且按钮恢复可用；未清 Windows 文件缓存。Uno 用 AVR 1.8.8、Wire；S3 用真实 3.3.6-cn、WiFi。每个格子一次，单位秒。

| 板卡 | 版本 | 首编 | 改码 | 原样 |
|---|---|---:|---:|---:|
| Uno | .57 | 7.48 | 2.31 | 1.10 |

| S3 CN | .57 | 58.60 | 18.73 | 2.92 |

Uno 先跑 .57，S3 先跑 .58。冷构建指空构建目录，不等于新装核心或冷系统缓存。所有改码均只编译 1 个对象并链接 1 次，原样均未启动编译器或链接器。每份导出固件均与当次收据核对，S3 合并镜像另外验证包含本次应用。这批没有上板烧录，不足以计算 P95。不能宣称回退后在所有机器更快。
