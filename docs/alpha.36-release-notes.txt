CK V9.1.0-alpha.36
2026-11-10

CK AI 增加可持续使用的聊天与上下文管理：
- AI 侧栏内可新建、切换、重命名、删除当前工程的聊天；自动保存消息、草稿和压缩摘要。
- 全局连接设置支持修改 API 地址、模型与密钥。密钥可使用当前 Windows 用户加密保存，取消记住后删除已保存的密钥。
- 可设置上下文预算和回复预留，输入预算接近 80% 时自动压缩历史。完整聊天仍保留在本机，AI 可按需搜索原聊天。
- 重复的只读工具查询引用本轮已有完整结果；切换工程或上下文压缩后重新核对，避免旧数据冒充当前状态。
- 显示估算上下文用量、请求次数，以及服务商实际返回的 token 用量。估算不是账单，也不扩大模型自身上限。
- 库能力查询沿用现有 ck-blocks.json，读取用途、单位、依赖、硬件资源、限制、示例和错误恢复；旧库不强制增加 AI 文件。

重新打开聊天不会恢复可执行的旧修改方案或编辑授权。方案仍须重新读取当前工程、预览确认；本地编译和真实硬件效果分别验证。
上下文压缩也需要模型请求；压缩失败、取消或预算不足时停止该次任务，保留聊天和当前工程。
当前是 CK 内部工具调用，不是独立标准 MCP 服务端。
详细使用方式见 engine/docs/ai-assistant-guide.md；作者声明规范见 engine/docs/library-ai-capabilities.md。
