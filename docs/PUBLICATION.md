# alpha.46 公开源码范围

公开日期：2026-11-16。版本：9.1.0-alpha.46。

本次将当前 CK 桌面、AI、V9 原生构建引擎、Rust 助手、更新协议、测试和网站源码更新到原有 `ovoVHV/CK` 仓库。保留已有公开 Git 历史与 Apache-2.0 许可，不导入本机研发仓库的私有历史。

不包含：API 密钥、服务端登录信息、更新签名私钥、用户聊天/工程、诊断 ZIP、原始机器证据、性能授权、下载的板卡 Core/工具链、驱动 ZIP、编译输出和依赖缓存。工具从上游按固定 SHA-256 单独准备。

## alpha.46 已有验证

- 155 项 AI 服务测试、15 项板卡身份/配置测试、版本契约、TypeScript/Vite 及 Rust release 构建通过。
- 本机真实桌面和 GCC：AVR Core 1.8.8 的 Uno、Nano、Mega2560、Duemilanove；ESP32 Core 3.3.6 的 ESP32、S3、C3、S2、C6、C5。共 10 个目标、20 次候选编译成功。
- 上述 AI 自动化使用受控 localhost SSE 响应，检查能力读取、生成库、安装和项目编译链路；不是实际模型智能水平评估，也不代表实体硬件测试。
- ESP8266、SAMD、RP2040、STM32 和未来架构声明还具有接口回归覆盖，但不能把模拟编译器测试说成真实编译资格。
- AVR 仿真仍限于已接入的 Uno/Nano 16 MHz ATmega328P 配置。AI 编程/补库/编译的通用接口不意味着任意板卡均可仿真。

这些是已有交付证据的摘要，不宣称本次源码发布重新跑过全部硬件、安装或双机性能验收。源码导出后的新增校验结果记录在发布说明中。

## 性能和反馈

性能依赖 CPU、磁盘、防病毒扫描、Core/库版本、完整板卡配置及构建路径。约 40% 的提速只描述部分已测试代码和对应对照，不是全面保证。遇到增量编译问题请报告最小复现、完整配置和脱敏日志；反馈前移除 Wi-Fi 密码、API 密钥和私人文件内容。
