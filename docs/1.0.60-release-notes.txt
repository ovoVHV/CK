CK LAB V1.0.60

「新建工程 → 选择目标板」分类栏改为单行“图标 + 厂商名”展示：
- ESP32 与 Arduino 分类使用随软件分发的本地厂商图标；
- 第三方板卡包可在 board.json 中声明 vendor 与本地 vendor_logo（PNG/SVG/WebP/JPEG，最大 256 KiB，断网重启后仍可本地显示），同一厂商的多块板卡自动归并为一个厂商入口；
- 单块开发板卡片仍保留各自独立的 icon 板卡图；未声明 vendor 的旧格式板卡包（仅 author）继续归入「自定义」；Logo 缺失或无效时给出质量检查提示并回退到通用图标；卸载某厂商最后一块板卡后自动切回「全部」，不会停留在空白页。

同时保留 V1.0.59 的冷热编译策略、Windows 深目录修复、多文件工程编译上传与离线外设样板库。
V1.0.59 用户可在 CK 主页直接在线更新，或下载 V1.0.60 安装包覆盖安装到原目录，无需卸载或重装核心包。
