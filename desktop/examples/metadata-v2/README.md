# 元数据契约示例

`ck-blocks-v2.example.json` 是库声明结构的说明与回归夹具，恢复了既有测试引用的缺失文件。内容复制自本机已安装的 `ck_example_i2c_sensor_v2/ck-blocks.json`，SHA-256 以本次审计记录为准。这是 CK 示例接口，不是某种真实传感器的硬件认证。本目录只有元数据副本，没有复制入口和示例程序，不可直接安装。

实际库应在自己的 `ck-blocks.json` 中描述真实的功能、单位、初始化、阻塞/超时行为、引脚和错误处理。CK 读取这些声明，不把它们当作经过真机验证的证据。旧库不需要为 AI 强制新增文件。
