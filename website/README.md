# CK LAB

CK 的展示、使用指南、驱动帮助与下载站点。静态网站，部署在现有 `ckswitch.site`，更新服务路径 `/ck-updates/` 独立保留。

## 构建与验证

在 V9.1 仓库根目录运行（使用已固定的 Node 24 与 desktop 前端依赖）：

```text
node website/build.mjs
node website/verify.mjs
node --test website/release.test.mjs
node website/serve.mjs
```

本地查看 `http://127.0.0.1:4178`。本地预览没有更新服务路由，会保留随页面生成的已核验版本；线上从同源更新清单读取发布版本并核验 Ed25519 签名后替换下载链接、摘要与说明。

构建默认使用随源码保存的 `website/published-release.json` 签名清单，构建时先验证 Ed25519 签名，作为静态回退记录。发布新安装包后，核验线上清单与安装包 SHA-256，再更新此文件并重新发布网站；首页和下载页即使无法在线检查更新也能显示正确版本。需要临时覆盖时设置 `CK_LAB_RELEASE_ENVELOPE` 指向相同格式的签名清单。不能把未上传的安装包记录用作公开下载目标。

功能文案在 `product-content.mjs`，功能页面为 `/features/`，性能和免责声明为 `/performance/`。`performance-summary.json` 是从已有报告整理的公开摘要，保留原报告摘要和每组比较对象；项目方的约 40% 当前实测反馈与历史组件/调度对照分开说明。官网更新不表示重跑了编译性能实验。

可设置 `CK_LAB_EVIDENCE_DIR` 另存本轮验证结果，`python website/package.py OUTPUT_DIRECTORY` 另存归档，保留之前的发布证据。

## 功能配图

首页与功能页使用 `media/` 中的十一组 CK 界面图；`manifest.json` 保存尺寸、说明、来源摘要及裁剪范围。原尺寸 WebP 为无损版本，768px 缩略图按需加载。点击图片可以放大，支持 Escape 关闭、焦点返回与手机横向查看。

编译、引脚、Core 图来自既有桌面截图；断点和轨迹图来自真实桌面 UI 的模拟串口回归，图注保留这个边界。恢复对比、串口曲线使用实际 React/Blockly 组件配合明确标注的示例数据，不表示硬件验证或性能成绩。

补拍入口：`node website/capture/build.mjs` 在本机 4180 端口提供组件场景；浏览器通过恢复页的「全屏对比」或 `?view=serial` 的「载入示例数据」查看。使用浏览器工具保存截图后运行 `python website/capture/prepare-media.py` 生成图片。截图场景、模拟事件入口和内部测试文件不会打进公共网站。

## 演示与实际 IDE 的关系

- 在线演示直接复用桌面版的 `blockly_setup.ts` 与 `arduino_generator.ts`，未另写一套假生成器。
- LED、串口、Wi-Fi 三个示例支持修改、代码预览、复制和导出 `.ck`。
- 仅在浏览器内执行编辑和代码生成；不提供在线编译、真实串口、上传或硬件运行结果。
- 页面不加载第三方 CDN、字体或分析脚本。板卡图与品牌图来自产品已有资产。
- 开源许可随产物提供。下载链接是发布清单指定的版本文件；浏览器验签失败时保留随网页部署的静态回退，并显示状态。

## 部署

`package.py` 为 `dist` 的每个文件生成 SHA-256 清单并输出静态归档。`deploy.py` 在服务器检查归档及所有文件，创建独立版本目录，校验 Caddy 配置后原子切换 `/srv/ck-lab/current`，保留旧目录与配置备份。网站上线不会修改客户端更新清单。

安装包发布与网站发布分开验证。更新安装包需沿用 `scripts/sign-update.mjs` 的签名流程。服务器不保存签名私钥。

## 已知边界

- 预览版，不宣传固定编译秒数或全部板卡均通过硬件测试。
- WCH / PL2303 原厂包由本站提供；CP210x / FTDI 为官方文件直链，受原厂访问策略影响。
- 本站示例是官方维护的入门内容，不提供社区投稿系统。


## Windows driver downloads (2026-11-09)

The driver page is rendered from drivers-catalog.json by drivers.mjs.
Original vendor ZIP files are kept in downloads/drivers/. stageDrivers
checks each published archive's length and SHA-256 before copying it into the
site. The deployment archive and existing live verifier cover these binaries
alongside website assets.

Hosted: WCH CH341SER 4.0, WCH CH343SER 2.2, Prolific PL23XX-M 4.10.0.0.
The convenience bundle contains the three original ZIP files and a Chinese
README; it is not an installer. Never remove vendor license or support files.

CP210x 11.6.0 was downloaded and signature-checked but is NOT mirrored:
its included license restricts standalone redistribution (sections 3e, 4b, 4g).
FTDI is external-only with a verified direct ZIP from its official Chinese site:
CDM 2.12.36.20. Both CAT signatures are Valid. Its complete license in the INF
limits redistribution to device sellers/distributors with the device (section
1.3), despite broader wording on the download overview. Do not silently add
either driver to the bundle. Both primary buttons now target official ZIP files,
not vendor landing pages. External downloads remain dependent on vendor access.

To update a driver: retrieve the vendor original, check the release notes and
applicable distribution terms, validate ZIP contents and the Windows signatures
without executing installers, use a versioned filename, update the catalog and
checksums, rebuild the bundle, then run the website checks and verify every live
download. Preserve prior versions for existing links when practical.

Audit: docs/audits/ck-lab-driver-downloads-2026-11-09.md.


## Driver installation guide

The static beginner guide at /drivers/install/ is generated by
driver-guide.mjs, with driver-guide.css and seven original SVG diagrams in
driver-guide-media/. Regenerate the diagrams with
python website/make-driver-illustrations.py. Each diagram is clearly labeled
as an illustration, not an actual screenshot or a successful hardware test.
The existing accessible lightbox handles enlargement.

The guide covers downloading, both layers of the convenience bundle,
SETUP installers, CP210x INF installation, FTDI Device Manager installation,
and selecting the matching COM port in CK. Match future instructions to the
actual ZIP contents when updating the catalog. Do not run installers for
website QA. All five driver cards link to their applicable guide section.


## 快速编辑与报错定位介绍（2026-11-09）

`editor-content.mjs` 管理首页 `#editor-tools` 与功能页三个独立锚点：
`#quick-select`、`#quick-insert`、`#block-errors`。入门指南也包含操作步骤。
`capture/editor-fixture.tsx` 复用 BlockDock、BuildIssueCards 和编译错误标记组件；
`?view=editor` 提供可操作的搜索/插入示例，`?view=error` 重现已验证的错误。
配图明确标为实际组件与示例数据，不声称在取图页面执行过编译。
报错定位修复从 alpha.31 提供；第三方作者无需新增诊断元数据，无法可靠归属的错误保留日志。
